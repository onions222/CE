006|Heading 1|1. 文档目的与范围
007|Normal|本文档定义 White Point Adjustment (WPA) 算法的数学模型、定点实现、硬件资源预算与验证准则，作为算法和 DIC 设计协同交付的基线文档。
008|Normal|适用范围：显示链路中的冷暖调节（WA_SEL 控制），运行时不使用 3x3 矩阵，仅使用 RGB 对角增益。
009|Heading 1|2. 术语与符号
010|Heading 1|3. 设计目标与约束
011|Normal|目标：
012|Normal|1) WA_SEL=64 对应 D65(6500K)；2) 冷暖端点覆盖 4500K~9300K；3) 运行时复杂度满足 DIC 实时预算；4) 亮度感知尽量稳定。
013|Normal|约束：
014|Normal|1) 运行时禁止 3x3 色彩适应矩阵；2) 采用 12-bin 亮度节点；3) 定点系数默认 UQ1.8，可选 UQ1.10。
015|Heading 1|4. 算法原理与数学模型
016|Heading 2|4.1 WA_SEL 到 CCT 映射
017|Normal|Eq. (1)  wa <= 64:   T(wa) = 6500 - (64-wa)*(6500-4500)/64
018|Normal|Eq. (2)  wa > 64:    T(wa) = 6500 + (wa-64)*(9300-6500)/63
019|Normal|锚点：T(0)=4500K, T(64)=6500K, T(127)=9300K。
020|Heading 2|4.2 CCT 到白点与基础增益
021|Normal|离线阶段按标准近似公式将 CCT 映射到 CIE 1931 xy，再转换 XYZ，最后通过 XYZ->linear RGB 矩阵得到目标白点 RGB。
022|Normal|Eq. (3)  G_base_float = RGB_target / RGB_neutral
023|Normal|Eq. (4)  Y_norm = 0.2126*G_R + 0.7152*G_G + 0.0722*G_B
024|Normal|Eq. (5)  G_base = clip(G_base_float / Y_norm, g_min, g_max)
025|Normal|其中 g_min=0.5, g_max=1.8（可按面板修订）。
026|Heading 2|4.3 三锚点压缩与运行时 base gain 插值
027|Normal|常驻仅保存三个锚点：G_warm (wa=0), G_neutral (wa=64), G_cool (wa=127)。
028|Normal|Eq. (6)  wa <= 64: G_base(wa)=G_warm + (wa/64)*(G_neutral-G_warm)
029|Normal|Eq. (7)  wa > 64 : G_base(wa)=G_neutral + ((wa-64)/64)*(G_cool-G_neutral)
030|Normal|说明：cool 端采用 /64（移位实现），最冷端将略弱于 /63 方案。
031|Heading 2|4.4 亮度衰减模型与 12-bin 展开
032|Normal|Eq. (8)  Y = (R + 2G + B)/4
033|Normal|Eq. (9)  atten(y)= { 0.55, y<=31; 0.55+0.45*(y-31)/96, 31<y<=127; 1.00-0.35*(y-127)/112, 127<y<=239; 0.65, y>239 }
034|Normal|Eq. (10) G_bin[i] = 1 + atten(y_i)*(G_base-1),  y_i in luma_nodes[12]
035|Normal|运行时先按当前 WA_SEL 生成当前 12x3 缓存，再按像素 Y 在节点间线性插值得到 gain(Y)。
036|Heading 2|4.5 定点量化与逐像素计算
037|Normal|设系数量化小数位 F_c，像素内部小数位 F_p。
038|Normal|Eq. (11) gain_fix = round(gain_float * 2^F_c)
039|Normal|Eq. (12) pixel_fix = round(pixel_linear * 2^F_p)
040|Normal|Eq. (13) out_fix = (pixel_fix * gain_fix + 2^(F_c-1)) >> F_c
041|Normal|Eq. (14) out_u8 = round( engamma( clip(out_fix/2^F_p, 0, 1) ) * 255 )
042|Heading 2|4.6 饱和度保护（可选）
043|Normal|Eq. (15) s = |R-G| + |G-B| + |B-R|
044|Normal|Eq. (16) w = clip((s1-s)/(s1-s0), 0, 1)
045|Normal|Eq. (17) out = in + w*(adjusted-in)
046|Heading 1|5. 实现流程
047|Normal|离线（高精度）：WA_SEL->CCT->xy->XYZ->RGB_gain，生成参考 128x3。
048|Normal|运行时（硬件主路径）：3锚点常驻 + atten LUT 常驻；WA 更新时生成当前 12x3；每像素仅做插值与定点乘移位。

054|Normal|每像素（sat_en=False）：比较11，加13，减5，乘6，除1，移位7，clip1。
055|Normal|每像素额外（sat_en=True）：abs+3，加+7，减+5，乘+3，除+1，移位+4。
