# White Point Adjustment 设计文档（CCT 驱动，硬件友好 RGB Gain）

## 1. 背景与目标

当前实现通过手工设定 `WARM_GAIN_GLOBAL/COOL_GAIN_GLOBAL` 调整冷暖，工程可用但与色温（CCT）没有直接物理对应关系。

本设计目标：
- 输入控制量仍为 `WA_SEL (0..127)`。
- 中性点固定 `WA_SEL=64 -> D65 (~6500K)`。
- 范围采用已确认方案：`4500K ~ 9300K`。
- 输出仍为每像素 `RGB gain`（对角形式），兼容现有 12-bin 亮度衰减流程。
- 运行时避免矩阵运算，满足 DDIC/硬件限制。

非目标：
- 不做全色域高精度色适应（不引入运行时 3x3 矩阵）。
- 不在本阶段引入复杂 ISP 级多通道色彩管理。

---

## 2. 总体方案

采用“两阶段”设计：

1. 离线阶段（工具链/预处理）
- 由 `WA_SEL -> CCT -> 白点 -> 线性 RGB gain` 计算 128 组基础 gain LUT。
- 可在 Python 脚本中使用完整色度学计算（允许矩阵），一次性生成常量表。

2. 运行时阶段（硬件/实时路径）
- 仅执行查表、线性插值（可选）和定点乘法。
- 不执行任何 3x3 矩阵运算。
- 保留现有 `12-bin atten` 机制做暗部/高亮保护。

结论：运行时仍是 RGB gain 模式，不需要矩阵模式。

---

## 3. 关键映射定义

### 3.1 WA_SEL 到目标 CCT

已确认约束：
- `WA_SEL=64 -> 6500K`
- `WA_SEL=0 -> 4500K`
- `WA_SEL=127 -> 9300K`

建议映射（分段线性）：

- `wa <= 64`:
  `T = 6500 - (64 - wa) * (6500 - 4500) / 64`
- `wa > 64`:
  `T = 6500 + (wa - 64) * (9300 - 6500) / 63`

说明：分段线性便于寄存器实现，也利于后续改成“感知均匀曲线”（可选）。

### 3.2 CCT 到白点

使用标准近似公式得到 `(x, y)` 白点坐标（例如常见 1667K~25000K 近似公式）。

建议实现策略：
- 离线计算时用高精度公式。
- 运行时不算公式，直接查 `WA_SEL -> gain` LUT。

### 3.3 白点到 RGB Gain

运行时目标是每档位得到 `gain = [gR, gG, gB]`，并保持亮度稳定。

归一化建议：
- 以 D65 档位为基准，保证 `WA_SEL=64` 时 gain 为 `[1,1,1]`。
- 对每个档位做亮度归一（例如固定 `Y` 或固定 `G=1` + 全局标定系数），避免整体明暗漂移。
- 最终 gain 夹紧到硬件安全范围（例如 `0.5~1.8`，按面板能力定）。

---

## 4. 运行时算法（无矩阵）

### 4.1 输入
- `WA_SEL`（0..127）
- 像素 `RGB`
- 亮度分段节点 `luma_nodes[12]`
- 衰减曲线 `atten(y)`（沿用现有三段式）

### 4.2 步骤
1. 从 ROM/LUT 读取该 `WA_SEL` 的基础 gain：`g_base = [gR,gG,gB]`。
2. 对每像素计算亮度代理 `Y = (R + 2G + B) >> 2`。
3. 用现有 `atten(Y)` 生成 per-pixel gain：
   `g(Y) = 1 + atten(Y) * (g_base - 1)`。
4. 在线性域（或现有设定域）执行逐通道乘法。
5. 保留现有饱和度保护和 clip 流程。

说明：步骤 1~4 均可用定点实现，仅含查表、加减、乘移位。

---

## 5. 数据与组件设计

### 5.1 新增数据
- `cct_gain_lut[128][3]`：每个 `WA_SEL` 对应基础 RGB gain。
- 可选 `cct_value_lut[128]`：用于调试/可视化。

### 5.2 代码组件（建议）
- `tools/gen_cct_gain_lut.py`：离线生成 LUT（可使用矩阵，仅离线）。
- `wpa/config.py`：支持从 `cct_gain_lut` 初始化 warm/cool 端点或直接走 128 档位。
- `wpa/core.py`：运行时只查表，不做色度矩阵计算。

### 5.3 固定点表示
- 沿用 `frac_bits`（例如 Q6.10 或 Q4.12）。
- 预量化 LUT：`gain_fixed = round(gain_float * ONE)`。
- 运行时乘法：`out = (in * gain_fixed + HALF) >> frac_bits`。

---

## 6. 误差与风控

### 6.1 误差来源
- CCT->xy 近似本身误差。
- LUT 量化误差（定点位宽不足）。
- 极端高亮/高饱和区域的 clip 或观感偏差。

### 6.2 控制策略
- LUT 生成时加入单调性检查（`WA_SEL` 变冷时 `B/R` 比值应整体上升）。
- 对 gain 设置上下限，避免溢出和色偏突变。
- 保留高亮衰减和 saturation protection。

---

## 7. 验证计划

### 7.1 数值验证
- `WA_SEL=64` 时输出应为 identity（误差 <= 1 LSB）。
- `WA_SEL` 从 0->127，目标 CCT 单调上升。
- `gR/gB` 随冷暖方向变化单调合理。

### 7.2 图像验证
- 灰阶卡：不同亮度下无明显色阶断层。
- 肤色、天空、草地场景：冷暖方向正确且不过饱和。
- 高亮区域（云层/灯光）无异常偏色和剪切。

### 7.3 硬件验证
- 统计每像素操作：仅查表+定点乘加，符合时序预算。
- 验证 ROM/LUT 占用与带宽。

---

## 8. 迁移策略

1. 第一步：保留现有算法主流程，仅替换 gain 来源为 `cct_gain_lut`。
2. 第二步：增加离线 LUT 生成脚本与自动校验。
3. 第三步：在固定点分支对齐同一 LUT，保证 float/fixed 行为一致。
4. 第四步：按面板实测结果微调 `4500/6500/9300K` 映射曲线（可选）。

---

## 9. 结论

该设计满足两点核心诉求：
- 增益由色温驱动，具备科学可解释性。
- 运行时不需要矩阵运算，仍是硬件友好的 RGB gain 路线。

后续若需要更高色度精度，可在离线 LUT 生成阶段升级模型，而不影响硬件运行时复杂度。
